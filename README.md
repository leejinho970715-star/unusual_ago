# UNUSUAL AGO | MBTI & Seasonal Fashion Curation Studio

![UNUSUAL AGO](https://img.shields.io/badge/MBTI-16%20Personalities-8b5cf6?style=for-the-badge)
![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-10b981?style=for-the-badge&logo=github)

16가지 MBTI 성향과 사계절 감성을 결합한 맞춤형 프리미엄 패션 큐레이션 스튜디오 **UNUSUAL AGO**입니다.

## 🌟 주요 기능 (Key Features)

1. **MBTI 16가지 성향 페르소나 (16 MBTI Personas)**
   - 4대 주요 그룹 (분석가형 NT, 외교관형 NF, 관리자형 SJ, 탐험가형 SP) 및 16가지 타입별 핏, 톤앤매치 큐레이션.

2. **사계절 무드 팔레트 (Seasonal Atmosphere)**
   - Spring 🌸, Summer 🏖️, Autumn 🍁, Winter ❄️ 계절별 소재 및 컬러 스와치 매칭.

3. **3초 AI 스타일 분석 퀴즈 (Interactive Style Quiz)**
   - 성향 그룹, 선호 계절, 무드 핏을 바탕으로 시그니처 룩북을 자동 추천하는 모달 퀴즈.

4. **나만의 시그니처 캡슐 (Personal Capsule Drawer)**
   - 마음에 드는 코디 룩북을 보관하고 언제든 확인할 수 있는 LocalStorage 캡슐 보관함.

5. **프리미엄 반응형 UI/UX & 다크모드 (Glassmorphism & Themes)**
   - 다크/라이트 모드 지원, 미세 애니메이션, 고품질 글래스모피즘 인터페이스.
